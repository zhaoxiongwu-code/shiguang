时光

把网页的文字和图片，存进你的 GitHub 仓库。

GitHub 连接

推荐用 Fine-grained token，只授权这一个仓库。 去创建 →

怎么创建令牌？
  1. 打开 Fine-grained tokens，起个名字，有效期按需。
  2. Repository access 选 Only select repositories，勾上 时光。
  3. Permissions → Repository permissions → Contents 设为 Read and write。
  4. 生成后复制，粘贴到上面。令牌只保存在本机浏览器里。

保存内容

每篇会生成一个独立文件夹，包含 index.md、index.html 和 assets/ 图片。
